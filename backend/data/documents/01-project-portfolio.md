# Helios Aerospace — Active Project Portfolio (FY2027)

Document ID: DOC-PORT-2027
Classification: Internal
Owner: Programme Management Office (PMO)
Last revised: 2027-04-02

## Purpose

This portfolio record lists every active engineering programme, its programme
director, its budget envelope and the component bill-of-materials line items
that the programme depends upon. Component identifiers referenced here are
maintained in the Component Register; this document does not record supplier
allocations.

## PRJ-PHOENIX — Project Phoenix

Project Phoenix is the next-generation avionics platform intended to replace the
legacy H-400 flight computer across the entire narrow-body fleet. The programme
entered Phase C (detailed design) in January 2027 and is currently tracking two
months behind its original baseline.

- Programme director: Elena Vasquez
- Budget envelope: EUR 84.2 million
- Phase: C — detailed design
- Target first flight: Q3 2028

Project Phoenix uses component C-17 as its primary inertial navigation element.
Project Phoenix also uses component C-22 for regulated power distribution and
component C-63 for flight data capture. The C-17 dependency is considered
programme-critical: no qualified alternate part has been introduced into the
Phoenix baseline, so any interruption in C-17 availability halts integration
testing within eleven working days.

## PRJ-AURORA — Project Aurora

Project Aurora delivers the ground segment for the company's low-earth-orbit
telemetry constellation, including three new ground station sites in Kiruna,
Perth and Punta Arenas.

- Programme director: Marcus Chen
- Budget envelope: EUR 52.7 million
- Phase: D — qualification
- Target site acceptance: Q1 2028

Project Aurora uses component C-45 for its Ka-band uplink chain and component
C-77 for antenna pointing. Aurora carries a dual-source mandate imposed at
programme approval, so both elements have a qualified second source held in
reserve.

## PRJ-TITAN — Project Titan

Project Titan is the heavy-lift launch vehicle upper-stage development
programme, and is the largest single capital commitment in the FY2027 plan.

- Programme director: Priya Raghunathan
- Budget envelope: EUR 143.9 million
- Phase: C — detailed design
- Target static fire: Q4 2028

Project Titan uses component C-31 in its cryogenic feed system, component C-58
for base heat shielding, and component C-22 for regulated power distribution.
C-22 is therefore shared between Titan and Phoenix, which the PMO has flagged as
a concentration point in the FY2027 portfolio review.

## PRJ-VEGA — Project Vega

Project Vega is the telemetry analytics and predictive-maintenance platform that
consumes flight data from the wider fleet.

- Programme director: Sofia Lindqvist
- Budget envelope: EUR 18.4 million
- Phase: B — preliminary design

Project Vega uses component C-63 for flight data capture, sharing that
dependency with Project Phoenix.

## PRJ-NIMBUS — Project Nimbus

Project Nimbus is the internal cloud and simulation infrastructure refresh. It
is a pure-software and datacentre programme and consumes no flight hardware
components from the Component Register.

- Programme director: Sofia Lindqvist
- Budget envelope: EUR 11.0 million
- Phase: E — operations

## Portfolio notes

The PMO records component dependencies only at the identifier level. Supplier
allocation, contractual coverage and supplier-level risk exposure are held in
the Component Register, the Supplier Directory, the Contract Register and the
Risk Register respectively. Programme directors are reminded that a component
identifier alone does not indicate which supplier is responsible for delivery.
